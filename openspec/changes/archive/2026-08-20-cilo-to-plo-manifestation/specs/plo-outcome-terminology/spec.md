## ADDED Requirements

### Requirement: Canonical PLO terminology
All user-visible surfaces, glossary entries, validation messages, and new code SHALL use Program Learning Outcome or PLO, and SHALL NOT introduce new Graduate Outcome or GO wording.

#### Scenario: Program Head outcomes surface uses PLO
- **WHEN** a Program Head opens the Program outcomes surface
- **THEN** the heading and controls use Program Learning Outcomes and PLO, not Graduate Outcomes or GO

#### Scenario: Mapping review uses PLO
- **WHEN** a Program Head opens the CILO-to-PLO mapping review
- **THEN** all outcome labels use PLO terminology

#### Scenario: Glossary defines PLO terms
- **WHEN** reading the outcomes domain glossary
- **THEN** Program Learning Outcome, Course Intended Learning Outcome, CILO-to-PLO mapping, and Manifestation are defined with the new meanings

#### Scenario: No new GO copy introduced
- **WHEN** any new copy, message, or label is added in the outcomes domain
- **THEN** it uses PLO terminology rather than GO terminology
