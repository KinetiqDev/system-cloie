# OpenSpec Deprecation — Migration Report

Date: 2026-09-03. Scope: every `openspec/` artifact audited against the current source, Prisma schema, migrations, tests, feature CONTEXT.md files, ADRs, and maintained docs. Evidence-based: claims were validated against code symbols, migrations, and tests before being treated as current. `openspec/` itself is **not** modified or deleted in this pass; deletion happens only after this report is reviewed.

Classification vocabulary: **1** current implemented domain behavior · **2** current cross-domain behavior · **3** durable architectural rationale · **4** active unfinished requirement · **5** Capstone-relevant traceability · **6** historical/superseded · **7** redundant (already represented elsewhere).

## Method

- Eight parallel audits covered the 40 main specs, the 8 active changes (all artifacts incl. `.openspec.yaml`), and the 16 archived changes (sampled at proposal/design/decisions/tasks/release-evidence level, with delta specs diffed against their synced main specs).
- A dedicated reference sweep located every OpenSpec mention outside `openspec/` (git-tracked and untracked), including `.omp/`, `.opencode/`, `.pi/`, `.fallowrc.json`, ADRs, runbooks, and migration SQL comments.
- Migrations below landed only after the claim was matched to code/tests; unmatched claims were recorded as conflicts or issues instead of being migrated.

## Conflicts discovered (detailed)

1. **auth/CONTEXT.md assignment matrix was stale** (pre-ADR-0019 wording: "Secretary retains Program-specific assignment mutation"). Contradicted by ADR 0019, `course-assignments/CONTEXT.md`, and `policies.ts` (`SECRETARY → allowed: false`). **Fixed** in this migration.
2. **Rollover DUPLICATE overclaim**: academic-calendar CONTEXT said duplicates "surface as ... DUPLICATE exceptions"; code defines `RolloverExceptionType.DUPLICATE` but never emits it (idempotent skip). **Fixed**; spec wording was already correct.
3. **Appearance control placement**: ADR 0010, design.md §4.4, and the activation runbook described an avatar-menu control + `Settings → Appearance` route; shipped code uses a standalone topbar/public trigger and no settings route. **Fixed in all three docs.**
4. **ADR 0013 stale integration paragraph**: claimed CourseAssignment does not yet reference CurriculumCourse; migration `20260810082518` + `resolveCurriculumCourseForAssignment` prove otherwise. **Amended with an update note.**
5. **ADR 0016 vs shipped AI boundary**: accepted option was de-identified raw-comment processing; shipped packet is aggregate-only. **Annotated as a shipped-state note** (more conservative than accepted).
6. **ADR 0005 ILO ownership superseded but unamended in body** — filed as #605 (not silently edited: institution-facing decision).
7. **curriculum-role-navigation delta vs `navigation.test.ts`**: spec + checked tasks say curricula exposed; tests assert omitted, and no routes exist. **Filed as #600** (decision needed: mount or park).
8. **GE analytics review-link promise** vs DTO without the field — **filed as #604** (triage decision).
9. **pre-oauth-legal-acknowledgement** enumerates 7 role actions; portal has 8 role cards. Behavior generalizes via `RoleSelectionCard`; recorded, no action.
10. **config.yaml stack version drift** (Next.js 16.2.x vs 16.3.3) — not migrated; package.json is authoritative.
